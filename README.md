# AWS Three-Tier Architecture with Auto Scaling

## Project Overview

This project demonstrates the design and deployment of a secure, scalable, and highly available Three-Tier Web Application Architecture on Amazon Web Services (AWS).

## Architecture Components

* **Web Tier:** Amazon EC2, Nginx
* **Application Tier:** Python, Flask, Amazon EC2
* **Database Tier:** Amazon RDS MySQL
* **Networking:** Amazon VPC, Public and Private Subnets, Internet Gateway, NAT Gateway
* **Load Balancing:** Internet-Facing and Internal Application Load Balancers
* **Security:** AWS Security Groups
* **Scalability:** EC2 Auto Scaling with CPU-based Target Tracking

## Project Tasks

* AWS Networking Infrastructure
* Web Tier Deployment
* Application Tier Deployment
* Database Tier Deployment
* Network and Instance Security
* Internet-Facing Application Load Balancer
* Internal Application Load Balancer
* Nginx Reverse Proxy for API Routing
* Flask and Amazon RDS Integration
* Complete Three-Tier Architecture Validation
* EC2 Auto Scaling (Bonus Task)
